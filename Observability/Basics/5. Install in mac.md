This guide outlines installing Prometheus on a Mac using Homebrew.

**1. Install Prometheus**
* **Prerequisite:** Check if Homebrew is installed by running `brew version`. If it's not found, install it from `brew.sh`.
* **Installation:** Run `brew install prometheus`.

**2. Configure Prometheus**
* **Configuration Path:** Navigate to `/usr/local/etc/`.
* **Key Files:**
    * `web.yml`: Configures the web interface.
    * `prometheus.yml`: Configures the Prometheus engine.
    * `prom.cert` & `prom.key`: Default self-signed certificates for HTTPS.
* **Disable HTTPS (Recommended):**
    * Edit `web.yml` (e.g., `sudo nano web.yml`).
    * By default, Prometheus uses HTTPS with self-signed certificates. These can cause connection problems, especially with Grafana.
    * It is recommended to comment out (using `#`) the two lines referencing `prom.cert` and `prom.key` to disable HTTPS and use HTTP instead.
* **Check Default Credentials:**
    * Edit `prometheus.yml`.
    * The default **username** is `admin`.
    * The default **password** is `password`.

**3. Run Prometheus**
* **Start Service:** Run `brew services start prometheus` to start it as a background service.
* **Access UI:** Open a browser and go to `http://localhost:1990`.
* **Login:** If prompted, use the default `admin` / `password` credentials.
