### Atlas_OME-Test – Dell OpenManage Enterprise Test Application

Designed and implemented a mock device test framework to validate OME features without physical hardware. 
Replaced real device dependencies with simulation templates, enabling automated testing of device discovery, alerting, and policy workflows. Improved reliability, scalability, and CI/CD automation, reducing test flakiness and accelerating release validation.



### OME_Test – Dell OpenManage Enterprise Test Application

Dell OpenManage Enterprise (OME) is a centralized console for managing datacenter servers, storage, and networking devices. 
I developed ome_test, a companion test application, to validate OME features without relying on physical hardware by using mock device simulation templates. This approach enabled automated testing of device discovery, alerting, and policy workflows while improving reliability, scalability, and CI/CD automation, reducing test flakiness and accelerating release validation.
