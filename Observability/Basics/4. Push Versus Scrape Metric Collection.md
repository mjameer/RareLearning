There are two main methods for collecting metrics and storing them in a time series database (TSDB): push and scrape.

**1. Push Method**
In this method, applications or microservices actively send (push) their metrics to an endpoint provided by the TSDB, using protocols such as TCP, UDP, or HTTP.

* **Example:** A Python application sends metrics to Graphite (a TSDB).
* **Aggregation:** Often, an agent or network daemon like **StatsD** is used as an intermediary. The application sends all its metrics to StatsD, which then aggregates them (e.g., calculates an average) before sending the final aggregated metric to the TSDB (like Graphite). This aggregation step is crucial to reduce the CPU, storage, and cost burden on the database.

**2. Scrape Method**
This is the opposite of the push method, where the system reads the metrics (implying the TSDB or an agent pulls them from the application).
